# Portfolio de Matías Argañaras

Editor de video. Sitio estático (HTML + CSS + JS, sin build), pensado para Netlify (formulario con Netlify Forms).

- `index.html`: todo el sitio. Para sumar un reel, copiar un `<button class="reel">` (instrucciones en el comentario de la sección Trabajos) y guardar la portada como `assets/img/reel-CODIGO.jpg`.
- Los reels se reproducen con el embed de Instagram, que se carga recién al tocar una portada.

Pendiente: WhatsApp o Instagram personal de Matías, foto, reel propio de presentación.

Parte de [MGM Studio](https://mgm-studio.netlify.app).
